# 🎨 바이브 코더 UI/UX 사전

> "그거 있잖아… 그 동그란 거…" 말고, 정확한 이름으로 AI에게 요청하세요.

**바이브 코더 UI/UX 사전**은 비전공 기획자와 개발자가 AI와 대화할 때 꼭 필요한 **45개 핵심 UI/UX 용어**를 한눈에 보여주는 웹 페이지예요.

각 용어 옆에 **실제로 움직이는 미니 UI 화면**이 붙어 있어서, "이 단어 = 이 모양"을 바로 외울 수 있어요.

🔗 **지금 바로 보기**: [https://ui-ux-dic.lovable.app](https://ui-ux-dic.lovable.app)

## ✨ 왜 만들었나요?

AI(Claude, ChatGPT, Cursor 등)에게 화면을 만들어 달라고 부탁할 때,

| ❌ 이렇게 말하면 | ✅ 이렇게 말하면 |
|---|---|
| "그… 위에 뜨는 알림창 같은 거" | "토스트(Toast)를 화면 우측 상단에 띄워줘" |
| "동그란 프로필 사진" | "아바타(Avatar) 컴포넌트를 40px로 만들어줘" |
| "페이지 아래 1, 2, 3 번호" | "페이지네이션(Pagination)을 10개씩 보여줘" |

정확한 용어를 알면 AI가 **훨씬 더 정확하게** 원하는 화면을 만들어줘요.

## 🚀 내 컴퓨터에서 실행하기

> 커뮤니케이션용으로만 보고 싶다면 위 링크만 열면 돼요.
> 직접 수정해보고 싶을 때 아래를 따라오세요.

### 준비물

- **Node.js**가 설치된 컴퓨터 (버전 18 이상)
  - 없다면 [nodejs.org](https://nodejs.org)에서 "LTS" 버전을 다운받아 설치하세요.
- **터미널(명령 프롬프트)** : 컴퓨터에 깔려있는 검은 창

### 1단계: 프로젝트 다운받기

```bash
# GitHub에서 코드를 내 컴퓨터로 가져오기
git clone <이 저장소 주소>
cd <프로젝트 폴더명>
```

### 2단계: 필요한 도구 설치하기

```bash
# 한 번만 실행하면 돼요. 1~2분 정도 걸려요.
npm install
```

> `npm`은 Node.js를 설치하면 따라오는 "도구 설치 도우미"예요.
> 위 명령어가 끝나면 `node_modules`라는 폴더가 생겨요.

### 3단계: 미리보기 실행하기

```bash
# 개발용 서버를 켜요. 화면이 자동으로 뜹니다.
npm run dev
```

터미널에 이런 메시지가 뜨면 성공이에요:

```
  VITE v7.x.x  ready in xxx ms

  ➜  Local:   http://localhost:5173/
  ➜  press h + enter to show help
```

브라우저에서 `http://localhost:5173/`를 열면 사전이 나타나요!

### 4단계: 수정하고 저장하면 자동 반영

- `src/data/terms.ts` → 용어 내용을 고치거나 추가할 수 있어요
- `src/components/Demos.tsx` → 각 용어의 미니 UI 모양을 바꿀 수 있어요
- `src/routes/index.tsx` → 메인 페이지의 레이아웃을 수정할 수 있어요
- 파일을 저장하면 브라우저가 **자동으로 새로고침**돼요

### 5단계: 인터넷에 올리기 (선택)

```bash
# 배포용 파일을 만듭니다. dist 폴더가 생성돼요.
npm run build
```

만들어진 `dist` 폴더를 [Vercel](https://vercel.com), [Netlify](https://netlify.com), [Cloudflare Pages](https://pages.cloudflare.com) 등에 끌어다 놓으면 인터넷 주소가 생겨요.

## 🙋 자주 묻는 짓긴 질문

**Q. 코드를 전혀 모르는데 수정할 수 있나요?**  
A. 네! `src/data/terms.ts` 파일만 열어서 글자를 고치면 돼요. AI(Claude, ChatGPT, Cursor)에게 "terms.ts 파일의 설명 문구를 이렇게 바꿔줘"라고 부탁하면 알아서 해줍니다.

**Q. 새로운 UI 용어를 추가하고 싶어요.**  
A. `src/data/terms.ts`에 `{ id, name, category, description, demoKey }` 형식으로 한 줄만 추가하면 돼요. 그리고 `src/components/Demos.tsx`에 같은 `demoKey` 이름으로 미니 UI를 그려주면 카드에 자동으로 붙어요.

**Q. 색상을 바꾸고 싶어요.**  
A. `src/styles.css` 파일 상단의 `--color-mint-500` 값을 다른 색상 코드로 바꾸면 전체 색이 바뀝니다.

**Q. 폰트를 바꾸고 싶어요.**  
A. `index.html` 상단의 Pretendard 주소를 다른 웹폰트 주소로 바꾸고, `src/styles.css`의 `--font-sans` 부분도 함께 수정하세요.
